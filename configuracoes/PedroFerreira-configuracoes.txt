============================================================
1. VISÃO GERAL
============================================================

O projeto conecta duas redes locais e uma rede externa simulada:

- Prédio A: 192.168.0.0/24
- Prédio B: 192.168.1.0/24
- Internet simulada: 209.165.200.0/24

O roteador R-COPA-NORTE realiza o roteamento entre os prédios e NAT para o acesso ao servidor externo Cisco.

Serviços disponíveis:

- site.com: servidor WEB do Prédio A
- vendas.com: servidor WEB do Prédio B
- cisco.com: servidor WEB externo que representa a internet
- DHCP: distribuição automática de IPv4 aos PCs e ao laptop do Prédio A
- DNS: resolução dos nomes site.com, vendas.com e cisco.com
- Wi-Fi protegido: redes PredioA e PredioB

Máscara utilizada nas três redes: 255.255.255.0 (/24)

3. CONFIGURAÇÃO DO ROTEADOR R-COPA-NORTE
============================================================

Modelo: Cisco 2911

enable
configure terminal
hostname R-COPA-NORTE

interface gigabitEthernet0/0
 description REDE_PREDIO_A
 ip address 192.168.0.1 255.255.255.0
 ip nat inside
 no shutdown
exit

interface gigabitEthernet0/1
 description REDE_PREDIO_B
 ip address 192.168.1.1 255.255.255.0
 ip nat inside
 no shutdown
exit

interface gigabitEthernet0/2
 description INTERNET_SIMULADA
 ip address 209.165.200.1 255.255.255.0
 ip nat outside
 no shutdown
exit

access-list 1 permit 192.168.0.0 0.0.0.255
access-list 1 permit 192.168.1.0 0.0.0.255
ip nat inside source list 1 interface gigabitEthernet0/2 overload

end
copy running-config startup-config

Resumo das interfaces:

- G0/0: 192.168.0.1/24 - Prédio A - NAT inside
- G0/1: 192.168.1.1/24 - Prédio B - NAT inside
- G0/2: 209.165.200.1/24 - Internet simulada - NAT outside
